🗄️ SQL QUEST

Aprende SQL mientras exploras un laberinto. Usa comandos SQL reales para moverte, combatir y recoger objetos.

📍 Objetivo: Llega a la salida usando la Llave Dorada.

🖱️ Cómo jugar:

SELECT * FROM mapa; → Ver tu posición y direcciones disponibles
UPDATE héroe SET posición = 'norte'; → Moverte al norte (sur, este, oeste)
SELECT * FROM héroes; → Ver tus stats (HP, ATK, nivel, oro)
INSERT INTO ataque; → Atacar al enemigo
UPDATE héroes SET hp = hp + 30; → Curarte (necesitas poción)
SELECT * FROM inventario; → Ver tus objetos

⚔️ En combate:

Derrota enemigos para ganar XP y oro. Recoge armas y armaduras para fortalecerte.

💡 Comandos extra:

SELECT hp FROM héroes; → Ver solo HP
SELECT COUNT(*) FROM inventario; → Contar objetos
SELECT COUNT(*) FROM enemigos; → Ver enemigos restantes
